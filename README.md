# 🌱 农场废旧农膜回收称重与补贴资格系统

回收站登记收料与分拣结果，审核人员确认补贴资格，管理员按地块掌握回收/合格/兑付并出
具兑付回执，种植户自助查询交膜量与最终补贴。

- **后端**：TypeScript + NestJS 11 + Prisma 6 + SQLite，JWT 登录与四角色鉴权
- **前端**：React 18 + Vite + 原生 CSS（无 UI 框架依赖）
- **外部设备本地模拟**：地磅读数（`ScaleService`）与兑付回执（`PayoutsService.mockReceipt`）
- **一条命令启动**：`./start.sh`

## 快速开始

```bash
./start.sh            # 首次自动 npm install、建库、播种示例数据，启动前后端
# 浏览器打开 http://localhost:5173
./start.sh --reset    # 删除数据库并重新播种三类示例场景
./start.sh --build    # 编译后以生产模式启动（node dist + vite preview）
```

也可以分开启动：`npm run dev:backend`（:3000）与 `npm run dev:frontend`（:5173）。
接口冒烟测试：先启动后端，再执行 `bash scripts/smoke.sh`。

## 业务流程与规则

```
过磅登记(收料员) → 分拣补充净重/等级/含土率 → 审核(审核员) → 补贴清单 → 兑付回执(管理员)
  毛重/皮重           A 级 100% / B 级 85%       │ 只有 APPROVED     一户一期一张
  来自模拟地磅         REJECT 不计               │ 才计入补贴量       重复提交幂等
```

已落地的硬性约束：

1. **泥土夹杂 > 10% 或质量等级 REJECT**：不能审核通过，只能驳回。
2. **同批膜重复过磅**：相同 `batchCode`（或同户/同地块/同膜种且毛重皮重完全相同）
   自动标记 `duplicateOf` 并给出警告，审核时禁止计入补贴。
3. **称重修正全程留痕**：原值、新值、原因、复核人写入 `WeightCorrection`；
   **收料员不能复核/审批自己登记的单据**（服务端强制 403）。
4. **补贴数量双重上限**：地块面积（亩数 × 100kg/亩）与当期总额度（500kg），
   按已通过单据先占额度、本单裁剪剩余空间，裁剪过程写入单据 `capNote`。
5. **兑付幂等**：`Payout` 对（期次, 种植户）有数据库唯一约束，另支持幂等键；
   重复提交/并发双击都返回同一张回执，金额绝不重复累加。
6. **数据隔离**：种植户接口只返回本人单据与回执。

## 示例数据（`./start.sh --reset` 可复现，ID 固定）

补贴期 `2026-Q3`：单价 2 元/kg，面积上限 100kg/亩，当期总额度 500kg。

| 场景 | 单据 | 结果 |
| --- | --- | --- |
| **A. 重量修正** | `2026-Q3-0001`（张种植·P-01） | 初称净重 120kg，复核复磅夹带石块，修正为 **118kg**，修正记录含原值/原因/复核人李审核，按 118kg 通过 |
| **B. 重复交膜** | `2026-Q3-0002 / 0003` | 同批次 `BATCH-Z-01` 两次过磅，第二单自动标记重复并**驳回**，只有首单 80kg 计补贴 |
| **C. 额度刚好到上限** | `2026-Q3-0004/0005/0006` | P-03（2亩）首单 200kg **恰好顶满地快上限**；118+80+200+102=**500kg 恰好顶满当期额度**；第 6 单虽通过但合格量被裁剪为 **0kg** |
| 附：泥土过多 | `2026-Q3-0007` | 含土率 15% + REJECT 等级，驳回不计补贴 |
| 兑付回执 | `PAY-2026-Q3-0001/0002` | 张种植 300kg/600 元、王种植 200kg/400 元（本地模拟回执） |

审核队列中还预留了 1 张待分拣单、1 张 B 级待审单，方便在页面上走完整流程。
运行期新增的规则演示（脚本 `scripts/smoke.sh` 覆盖）：收料员自审 403、收料员
修正自己单据 403、重复兑付返回同一回执、额度满后新单合格量裁剪为 0。

## 主要接口

| 方法 & 路径 | 角色 | 说明 |
| --- | --- | --- |
| `POST /api/auth/login` | 公开 | 登录获取 JWT |
| `POST /api/tickets` | 收料员 | 过磅登记（毛重/皮重取模拟地磅，自动查重） |
| `POST /api/tickets/:id/sorting` | 收料员 | 补充分拣净重/等级/含土率 |
| `POST /api/tickets/:id/corrections` | 审核员 | 称重修正（原值/原因/复核人留痕） |
| `GET  /api/review/pending`、`POST /api/review/:id` | 审核员 | 待审队列、通过/驳回（含上限裁剪） |
| `GET  /api/admin/plot-summary`、`/api/admin/quota` | 管理员 | 地块汇总、额度看板 |
| `POST /api/payouts` | 管理员 | 生成兑付回执（幂等，返回本地模拟回执） |
| `GET  /api/farmer/dashboard` | 种植户 | 本人交膜量、进度、预计/已领补贴 |

```
frontend/src/pages/        四个角色各自的页面
scripts/smoke.sh           业务规则接口冒烟测试
```
